# 文案怎麼寫得不像 AI 寫的

文案是課程唯一直接對使用者說話的地方。技術上它只是設定檔的字串，但讀者用它
判斷這門課值不值得信——而 LLM 寫出來的中文有一組很固定的痕跡，讀過幾篇就認得。

這些痕跡不會讓 `make build` 掛掉，網站看起來也完全正常。`make audit` 的「文案」
區段會把最好抓的幾類列成**警告**，其餘的要自己讀。

樣式取自 Wikipedia:Signs of AI writing（WikiProject AI Cleanup 整理），
中文對照見 <https://github.com/kevintsai1202/Humanizer-zh-TW>。

## 一句話版本

**寫具體的事實，不要寫關於事實的感想。**

改寫前：

> 這門課的實證查核彰顯了其對科學嚴謹性的堅持，不僅提供了豐富的訓練內容，
> 更為使用者奠定了正確認識體態的基礎。

改寫後：

> 27 個主題經 OpenEvidence 查證，每一則都附原始文獻連結。

## audit 會抓的（警告）

| 痕跡 | 長什麼樣 | 怎麼改 |
|---|---|---|
| 揭示前的破折號 | 「答案沒有想像中好聽**——**但講清楚比較誠實」 | 改成句號。破折號在這裡是替讀者製造停頓 |
| 否定式排比 | 「這**不只是**一門課，**而是**一種態度」 | 只講你真正要講的那一半 |
| 三個並排的粗體 | 「告訴你三件事：**A**、**B**、**C**」 | 留一個真正的重點，其餘寫成白話 |
| 宣傳性語言 | 「這是跟其他體態課**最大的差別**」 | 拿掉最高級。要主張比別人好，得給得出依據 |
| 模糊歸因 | 「**專家認為**體態會導致疼痛」 | 指名道姓：哪一篇、哪一年。這門課有 PMID，用它 |
| 膚淺的意義昇華 | 「**彰顯了**」「**標誌著**」「**奠定了基礎**」 | 刪掉整句，或換成一個具體事實 |
| 填充連接詞 | 「**此外**」「**簡言之**」「**值得注意的是**」 | 刪掉，句子的意思不會少 |
| 通用積極結論 | 「**未來可期**」「邁出了重要的一步」 | 換成一件具體會發生的事 |

檢查只在 `site.locale` 是 `zh-*` 時跑——詞表是中文的，套到別的語系一個字都不會
命中，卻會讓人以為檢查過了。

## audit 抓不到、要自己讀的

**三段式法則。** LLM 很愛把想法湊成三組來顯得完整。這門課真的有三種動作類型
（放鬆／拉伸／訓練），寫「三類」是事實不是修辭；但「更快、更強、更持久」就是。
分辨方法：**拿掉一項，句子有沒有變得不完整？** 沒有的話那三項就是湊的。
兩項通常比三項好。

**語域。** 「東西」「耐操」「自測」「站不站得住腳」讀起來親切，但這門課的賣點是
實證嚴謹，語域不一致會讓人覺得前後不是同一個人寫的。決定一個語域然後守住它。

**金句。** 聽起來可以直接截圖轉發的句子，多半是為了聽起來好聽而寫的。
「與其讓你練完才發現，不如一開始就講清楚」——刪掉之後資訊一點都沒少。

**節奏。** 連續三個句子一樣長就打斷一個。段落不要每一段都用一句漂亮的短句收尾。

**虛假範圍。** 「從 X 到 Y」只有在 X 和 Y 真的在同一個尺度的兩端時才成立。
「從頸椎到足踝」可以，因為那是解剖學上真的從上到下；「從評估到人生」不行。

## 一個刻意不採用的建議

Humanizer 原文主張「注入靈魂」：適當用第一人稱、承認複雜感受、允許一些凌亂。
那是部落格的語域。課程文案要的是**正式而具體**，不是有個性——所以只取
「去除 AI 痕跡」的部分，不取「加入作者聲音」的部分。

兩者的共同點才是重點：**具體優於模糊**。

## 改完之後

```bash
make audit          # 「文案」區段會列出還剩哪幾處
```

警告不擋交付。逐條看過，接受的就留著，並在交付說明裡講清楚為什麼——
把門檻放寬到全部通過等於沒有檢查。
