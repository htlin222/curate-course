# 體態矯正課程網站 — 設計

2026-07-25

## 要解決的問題

把一份十二章的體態課程大綱，變成一個可以實際用的自學網站：371 個單元
各自配上 YouTube 上現存最好的示範影片，並標註每個體態問題在醫學文獻中
的實證強度。

## 三個關鍵決策

**一、371 支影片全配，不留佔位。** 較省事的做法是只配 37 支主課、
Part 2 只列動作名稱。但跟練清單沒有連結就只是一張紙，這門課的價值恰好
在「馬上能跟著做」。代價是搜尋與驗證的工作量，用九個並行 agent 分章消化。

**二、加權分配而非平均攤。** 334 支跟練影片依「久坐族盛行率 × 涉及肌群數」
分配：頭前伸、駝背、圓肩、骨盆前傾各 17–18 支，軍人頸、胸椎過直、垂肩、
上X下O 各 9 支。平均攤會讓罕見問題塞滿湊數動作，常見問題反而不夠深。

**三、實證查核的結果照實寫，包括對課程不利的部分。**
這是整個專案最重要的決定。24 個體態問題 + 3 個核心觀念全部經 OpenEvidence
查證，9 題被判為 contested——而且正好是體態課最愛賣的那幾個（圓肩、骨盆前傾、
腰椎過度前拱、假胯寬）。這些結果原封不動放進網站，contested 標籤直接顯示在
單元標題列，不必展開就看得到。

## 資訊架構

單一靜態站，資料驅動渲染。371 個單元用手寫 HTML 不可維護，
上 SSG 又對一個純靜態站過度工程。

```
data/ch*.json ─┐
               ├─► build.py ─► public/course.json ─► app.js ─► DOM
data/oe-*.json ┘      │
                      └─ 配額驗證：單元數與影片數不符即建置失敗
```

單元資料模型：

```json
{
  "id": "ch5-u1", "name": "駝背", "type": "posture",
  "assessment": "可自測的步驟",
  "tight": ["緊繃肌群"], "weak": ["無力肌群"],
  "lesson":  { "title", "channel", "url", "duration", "why" },
  "drills":  [{ "name", "en", "kind", "target", "dose", "url", ... }],
  "evidence": { "evidence_grade", "pain_link", "intervention", "citations" }
}
```

`kind` 三選一：`release` 🔵 / `stretch` 🟢 / `train` 🔴。

`concept-1/2/3` 三題不屬於任何章節，抽出來當首頁的「這門課的立場」，
同時透過 `EVIDENCE_ALIAS` 接回觀念篇對應的單元。

## 影片連結的可信度

單元格數 371 個，最大的風險是連結是捏造的。防線有三層：

1. **策展規格**（`docs/VIDEO_SPEC.md`）明令禁止憑記憶拼湊 video ID，
   找不到合格影片就寫 `null` 加註原因
2. **agent 自驗**：先從實際搜尋結果取得真實 video ID，再逐支打
   YouTube oEmbed 端點確認存在
3. **獨立重驗**（`verify_links.py`）：不信任任何上游宣稱，建置後對
   course.json 內全部連結重打一次 oEmbed

過程中確認的兩件事：`WebFetch` 直接打 `youtube.com/watch` 會被 Google
擋成 captcha；無 cookie 的 `yt-dlp` 會回報 "Sign in to confirm you're not
a bot"，據此判定影片失效是誤判（實測有一支被誤殺的影片其實可正常播放）。
**oEmbed 是這裡唯一可靠的程式化驗證途徑。**

## 視覺

Primer 設計語彙用 CSS 變數自行實作，不引入套件——零外部請求，
CF Pages 冷啟最快。深淺色雙主題，跟隨系統偏好並可手動覆寫，
`data-theme` 一律勝出。

Lucide 圖示（38 個）在建置時打包成 SVG sprite 內嵌進 `icons.js`，
啟動時注入 DOM，同樣零外部請求。

進度追蹤走 localStorage，無帳號無後端。

## 刻意不做的

- **評分與學員數**。原始規格有「⭐ 4.8 / 7,541 students」，但這是一門
  剛策展出來的課，沒有真實評分與學員。Hero 的統計數字全部改成可從
  course.json 實際算出來的：單元數、影片總時長、體態問題數、實證查核題數。
- **影片內嵌播放**。嵌入會拖慢頁面且有版權疑慮，一律外連原頻道。
- **搜尋後端**。371 個單元的前端全文過濾綽綽有餘。
